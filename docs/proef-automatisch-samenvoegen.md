# Proef: automatisch samenvoegen bij groen

Datum: 18 november 2026. Proefbestand, geen spec of ADR; het verdwijnt in de PR die het nieuwe model bouwt.

Deze PR raakt alleen een pad zonder code-eigenaar en is geopend onder het account van de eigenaar. Verwacht: nadat de
eigenaar op de PR "Enable auto-merge" heeft aangezet, voegt GitHub hem zelf samen zodra de verplichte checks groen zijn,
zonder review en zonder verdere handeling.

De tegenproef is een PR op een beschermd pad: die blijft geblokkeerd, ook met groene checks, tot de eigenaar hem in de
browser samenvoegt met de bypass van de beheerder.
