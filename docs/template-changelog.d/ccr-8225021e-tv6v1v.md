- `check:migrations` en de tweede bouw van `check:snapshot` behandelen een herhaalde CI-run van een oudere push op main nu
  als main (leerpunt #809, spec `template-update` AC-8 verruimd): `vergelijkingspunt` in `scripts/kit/check-migrations.mjs`
  kijkt of HEAD al in de base zit (ook een branch zonder eigen commits die achterloopt), niet of HEAD gelijk is aan de
  base. Een oudere toegevoegde migratie wordt bij een rerun dus niet meer overgeslagen; voor branches met eigen commits
  verandert niets (`test/rails/migratie-volgorde-main-rerun.test.ts`).
